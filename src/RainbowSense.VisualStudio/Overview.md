# RainbowSense

IntelliSense enhancements for Blazor and Razor markup with DevExpress Blazor component completion.

## Features

* Razor directive completion (`@page`, `@inject`, `@code`, `@layout`, `@rendermode`, ...).
* Completion list enriched with Blazor directives, injectable services and frequently used markup components.
* DevExpress Blazor component tag completion, including grid, layout, form layout, chart and editor controls.
* Configurable sorting and filtering of the completion list inside Razor files.

## Options

Settings are stored per user under `%LOCALAPPDATA%\RainbowSense\settings.json` and can be edited from
`Tools > Options > RainbowSense > General`.
