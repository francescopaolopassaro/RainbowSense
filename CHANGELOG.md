# Changelog

## 1.0.0

* Initial release.
* Razor directive completion with snippets.
* Built-in Blazor component tags and parameters.
* DevExpress Blazor 26 component tags, parameters and namespaces generated from the shipped assemblies.
* Markup snippets for the most common Blazor and DevExpress components.
* Description tooltips generated from the XML documentation of the libraries.
* Settings stored in `%LOCALAPPDATA%\RainbowSense\settings.txt`.
